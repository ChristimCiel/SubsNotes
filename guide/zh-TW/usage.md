# 使用 SubsNotes

[English](../en/usage.md) · [繁體中文](usage.md) · [首頁](../../README.zh-TW.md)

## 第一次連接

1. 到 [Releases](https://github.com/ChristimCiel/SubsNotes/releases) 下載 `subsnotes-subscription-review.zip`，在 Claude 技能設定上傳並啟用。
2. 在 Claude 連接要整理的 Gmail 帳號。帳號必須能使用原生 Gmail、Artifact 與個人儲存空間；這些能力不是由 SubsNotes 提供。
3. 對 Claude 說：**「使用 SubsNotes 整理我的個人訂閱，將帳本保存在私人空間，並以繁體中文開啟已儲存的儀表板。」**
4. 核對唯讀權限與 **Only you／只有你** 分享設定，保留私人 Artifact 連結。
5. 選「**檢查 Gmail**」。若出現「**繼續檢查**」，代表所選搜尋尚未完成；查詢完成後，仍可能有資料需要確認。

請先說明要整理個人還是商務訂閱。客戶向你的公司購買商品，不是你自己的訂閱支出。

## 看懂清單

| 檢視 | 內容 |
| --- | --- |
| 訂閱 | 服務清單、已記錄方案、續訂／使用期間證據及來源歷史；選月份時查看該月服務期間依據，不會虛構付款。 |
| 付款 | 已有來源紀錄或由你確認，且可歸屬所選期間的付款；請留意來源標籤。 |
| 其他與待核對 | 涵蓋所有日期的發票、單次消費、退款及仍需處理的紀錄。 |

切換月份會保留目前檢視。換分頁後若找不到紀錄，先確認搜尋文字是否仍在。金額下方的發票待核對入口涵蓋所有日期。提供者名稱可能不同於產品名稱，例如可以搜尋 OpenAI 或 ChatGPT。

## 確認與更正付款

1. 開啟個別發票或付款紀錄。
2. 選「**確認付款**」，核對實際付款金額與幣別。折扣或按比例補差額可能不同於標準方案價格。
3. 選擇你知道的精確程度：
   - **精確日期：**實際付款的年、月、日。
   - **只確認月份：**付款月份，不補上一個虛構日期。
4. 選「**儲存確認**」，等待儲存成功訊息。

未來預計續費不等於已付款；確認流程會拒絕未來付款日期／月份，請填你實際能確認的時間。

「**由你確認**」代表本人回報，不會改動原始郵件、驗證寄件者、宣稱銀行已入帳或取消訂閱。只填月份時顯示「**已確認月份・未指定日期**」；只會計入你確認的月份一次，不會變成該月一日的交易。

用「**編輯確認**」更正資料。「**撤回確認**」會撤回本人確認的覆寫，不會刪掉原始證據，也不會撤銷業者的實際交易。原始來源與確認歷史會保留給資料處理器。

後來的來源若有矛盾，請查看兩邊證據。你的確認仍是本人回報的金額／日期，來源矛盾另外標示，不會因此把矛盾證據變成已與銀行核對的付款。新的 AI 擷取不能默默取代你的確認；AI 提案在你明確確認前仍是提案。另一個視窗若已更動帳本，請先重開最新紀錄，再重試儲存。

如果確實有付款，但不知道時間，請保留日期待確認，不要選發票日或收信日代替。紀錄仍會保留供核對，可開啟原信或查看業者／信用卡交易明細。

## 金額、日期與標籤

- **原始幣別：**每筆金額會保留原幣；只有 `$` 不會自動當成美元。
- **參考換算：**採有日期的參考匯率估算，不是信用卡歷史匯率或手續費。
- **年費：**全額計入已確認的付款月份，不會除以十二。
- **月份確認：**以月份儲存，不是精確日交易。
- **發票開立日、收信日、預期續費日：**與付款日分開。
- **退款：**與付款總額分開；業者記錄退款不等於銀行已入帳。
- **最早來源信件：**是最早觀察到的證據，不一定是首次訂閱日。
- **最近讀取來源：**是讀信時間，不是向業者即時驗證的時間。

尚未確認、金額／幣別未知或矛盾的紀錄會保留顯示，不納入統一合計。明確的本人確認可提供你回報的金額／幣別，與來源的分歧仍可辨識。未完成掃描不代表零支出，也不代表已取消。

## 重開與更新

- **開啟原本私人 Artifact：**讀取既有帳本。需要時可說「**開啟我已儲存的 SubsNotes 儀表板，不要建立另一份帳本。**」
- **重新整理：**重讀已儲存資料，不搜尋 Gmail。
- **檢查 Gmail：**透過既有連線搜尋帳務變更。
- **資料與更新設定 → 補查所選月份：**檢查該月較早的帳務證據。
- **自動更新：**頁面開啟且位於前景時，最多每十五分鐘檢查一次；隱藏或關閉頁面會暫停。尚未完成的歷史搜尋仍需繼續。

編輯或同步時只開一個可寫入的儀表板，等待儲存確認後再關閉。新對話仍使用同一份權威帳本；另一個助理或新的 Artifact 不會自動共享資料。

## 語言與地區格式

使用「**English／繁體中文**」按鈕切換，偏好儲存在同一份帳本。正式語言代碼為 `en`、`zh-TW`，舊的 `zh` 設定仍相容。

日曆日期會保留原本的日／月份精確程度，不會因時區換算被移到另一個月份。幣別依各自的小數位數顯示；切換語言或顯示幣別，不會改動原幣、來源金額或確認精確程度。

## 管理訂閱

「**前往管理訂閱**」會開啟業者頁面；先選付費帳號，再核對業者目前條款並完成操作。透過 App 商店購買的方案，須回原商店管理。

SubsNotes 不會代為取消。確認付款不會開啟或關閉續訂。再看日期只是面板內的紀錄，不會建立行事曆事件或發送通知。
