# 常見問題與疑難排解

[English](../en/help.md) · [繁體中文](help.md) · [首頁](../../README.zh-TW.md)

## 不連接 Gmail 可以試用嗎？

可以。[公開示範](https://christimciel.github.io/SubsNotes/confirmations.html) 與本機範例都使用合成資料，不會尋找你的訂閱或發送通知。

## SubsNotes 免費嗎？

專案以 MIT 免費提供。Claude 網頁版仍需你自己的相容 Claude 能力，並使用該帳號額度；SubsNotes 不提供付費 Claude 帳號或 API 額度。本機合成範例不需帳號。

## 為什麼發票沒有計入付款？

發票金額或開立日，本身不能證明實際付款時間。可查看來源，或用「**確認付款**」填入自己知道的資料，選精確日期或只確認月份。本人回報與來源證據、銀行對帳分開標示；未知資料會保留，不會被當成零支出。

## 我確實有付，但不知道哪一天

如果能確認月份，選「**只確認月份**」。不要拿發票日、收信日、信用卡帳單月份或繳費期限代替。如果連月份也不知道，先保留待確認，直到取得交易日期或能由你明確確認。

## 找不到某筆付款或服務

1. 清空搜尋文字，確認目前分頁與月份。
2. 用發票待核對入口查看所有日期的紀錄。
3. 同時試試提供者名稱與產品名稱。
4. 查看是否還有搜尋未完成、或來源仍待複核。
5. 先開啟原始來源，再更改欄位。

部分查詢不等於完整信箱稽核。查詢即使完成，陌生格式或語言也可能仍無法完整擷取。

## 面板空白，或顯示載入太久

使用平常登入的瀏覽器重開同一個已儲存 Artifact，重試一次，並確認帳號仍有需要的原生能力。若顯示仍失敗，可以要求有日期的純文字表格。不要為了顯示既有資料建立替代帳本或擴張權限。產生 HTML 不代表平台已成功顯示它。

## 儲存失敗，或另一個分頁更動了資料

保留原本頁面與資料，關閉其他可寫入副本，重開同一份私人 Artifact，先看最新儲存的確認，再重試原本修改，並等待儲存成功。若儲存結果不明，不要連續提交舊資料，也不要用過期匯出覆蓋目前帳本。

## AI 會改掉我已確認的付款嗎？

受支援的來源更新路徑會保留本人確認與原始證據。需要更正時用「**編輯確認**」，撤回時用「**撤回確認**」。AI 擷取不等於本人確認。請保持同一時間只有一個可寫入儀表板；不支援直接整份替換帳本，平台儲存失敗也不等同於正常重掃。

## 為什麼助理讀不到收據附件？

AI 平台必須真的支援讀取附件／文件；附件資訊或連結不等於文件內容。加密 PDF 可能需要你先在本機解鎖。必要時只提供相關收據／交易列，不要提供身分證、完整卡號、銀行密碼或 PDF 密碼。連接 Gmail 不會自動解開受保護文件，也不等於授予業者帳戶權限。

## 再看日期會發通知嗎？關閉頁面仍會掃描嗎？

不會。再看日期只是已儲存的筆記；Claude 儀表板不會發通知，自動 Gmail 檢查在頁面隱藏或關閉後也會暫停。其他平台排程或本機背景程式，須另外授權並實際測試。

## 能直接幫我取消訂閱嗎？

不能。「**前往管理訂閱**」會開啟業者頁面，由你向業者或原 App 商店確認變更。儀表板狀態或付款確認不會改動業者收費。

## ChatGPT 能自動開啟 Claude 的帳本嗎？

不能，兩邊儲存空間不同。請明確提供私人匯出或相容本機資料。產生的視覺畫面是快照，不是共用儲存或即時同步連線。
