# Contributing

Bug reports and small fixes are welcome. Use fictional examples and include reproduction steps. Never attach private messages, tokens, receipts, account data or financial screenshots.

Use Node.js 22+. Install with `npm ci --prefix renew-before-service`, then run `npm test` and `npm run check:demo`. Native core changes also need `swift test` in `renew-before-mac/`.

Contributions are submitted under MIT. Retain third-party notices and contribute only material you have permission to share. See [SECURITY.md](SECURITY.md) for private vulnerability reporting.
